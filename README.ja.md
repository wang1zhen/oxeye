# Oxeye

[English](README.md) | [简体中文](README.zh-CN.md) | [日本語](README.ja.md)

Rust と egui で作られた軽量なデスクトップ画像ビューアー兼エディターです。フォルダーの素早い閲覧、大きな画像の表示、手軽なトリミング・回転・反転、シンプルでクロスプラットフォームな UI を重視しています。

## 機能

- 下部のプレビュー付きでフォルダー内をすばやく閲覧。
- CBZ/ZIP、CBR/RAR、CB7/7z を展開せず仮想フォルダーとして閲覧。
- 大きな画像もタイル表示で元のディテールを保って表示。
- ズーム、パン、ウィンドウに合わせる、原寸表示、90° 回転、全画面。
- 軽量で非破壊な編集：縦横比プリセット付きトリミング、回転、反転、取り消し。書き込み前にプレビューで確認できます。
- 確認のうえ元ファイルを上書き、または PNG/JPEG/WebP/BMP で名前を付けて保存。書き込みは原子的で、失敗しても元ファイルは壊れません。
- 現在の画像をクリップボードへコピー。
- 右から左に進む見開きの Book モード。横長ページの自動判定と `W` による手動切替に対応。
- アーカイブ内の読書位置を保存して再開。
- 隣接画像のプリロードで切り替えを滑らかに。
- すっきりとしたシンプルな UI。

## 編集と保存

- 編集できるのは静止画像 1 枚の PNG、JPEG、WebP、BMP（書庫内ファイルは「名前を付けて保存」のみ）です。GIF、TIFF、ICO は読み取り専用で、アニメーションや複数ページを無言で 1 フレームに潰すことはせず編集自体を拒否します。
- `C` で編集を開始します。表示中の回転は開始時に一度だけ焼き込まれ、終了すると元の画像と向きに戻ります。トリミングの比率は自由、1:1、4:3、3:2、16:9、元画像です。
- `Ctrl`/`Cmd`+`S` は完全なパスと保存形式を示す確認のうえ元ファイルを上書きします。`Ctrl`/`Cmd`+`Shift`+`S` は別名保存です。未知の拡張子は推測せずエラーにします。
- 上書きは同一ディレクトリの一時ファイル、`fsync`、原子的な rename を使います。中止や失敗時は元ファイルのバイトと権限を変更しません。
- EXIF、ICC/XMP、アニメーションは保持されません。JPEG は非可逆で再エンコードされ（品質の既定値は 90）、WebP は可逆のみのためファイルが大きくなることがあります。

## ダウンロード

インストーラーは [GitHub Releases](https://github.com/wang1zhen/oxeye/releases) にあります。
Windows MSI は未署名のため SmartScreen が警告する場合があります。macOS DMG は
ad-hoc 署名のみで未公証です。Gatekeeper に拒否された場合は右クリックの「開く」、
またはシステム設定から許可してください。Linux x86_64 は Ubuntu 22.04 / glibc 2.35
以降が基準です。AppImage にもホスト側の OpenGL/EGL、X11/Wayland ライブラリと
デスクトップ portal が必要です。
サードパーティ通知：[THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。

## クイックスタート

```sh
cargo run --release --locked -- path/to/image.png
```

パスを指定しない場合は空のウィンドウが開きます。Open ボタン、`Ctrl`/`Cmd`+`O`、またはファイルのドラッグ＆ドロップで開けます。

## 対応形式

- 編集後に書き出せる形式：PNG、JPEG、WebP、BMP。
- 読み取り専用：GIF（アニメーション）、TIFF、ICO。この版ではこれらの形式の編集・上書きはできず、アニメーション GIF の編集を静止画へ無言で縮退させることもありません。
- アーカイブ：CBZ/ZIP、CBR/RAR、CB7/7z を仮想フォルダーとして読み込み、ディスクへ展開しません。書庫内ファイルは「名前を付けて保存」で書き出せますが、その場で上書きはできません。
- ソリッド RAR/7z のページは先行ページのデコードが必要な場合があります。読書位置の指紋はアーカイブのパス・長さ・更新時刻を使うため、同じメタデータの置換は検出できないことがあります。

## 操作

| 操作 | キー |
| --- | --- |
| 開く | `Ctrl`+`O` / `Cmd`+`O` |
| 前 / 次 | `PgUp` / `PgDn` |
| 10 ファイル移動 | `Up` / `Down` |
| Book モード切替 | `M` |
| 横長ページ切替 | `W` |
| フィット / 原寸 | `1` または `9` / `0` |
| ズーム | `+`、`-`、またはホイール |
| 画像をコピー | `Ctrl`+`C` / `Cmd`+`C` |
| 回転 | `Ctrl`+`R` / `Ctrl`+`L`（macOS は `Cmd`）。閲覧中は表示回転、編集中は画像回転 |
| 編集開始とトリミング | `C` |
| トリミング適用 / 取消 | `Enter` / `Esc` |
| 左右 / 上下反転 | `X` / `Y` |
| 編集を取り消す | `Ctrl`+`Z` / `Cmd`+`Z` |
| 保存（上書き・要確認） | `Ctrl`+`S` / `Cmd`+`S` |
| 名前を付けて保存 | `Ctrl`+`Shift`+`S` / `Cmd`+`Shift`+`S` |
| 全画面 | `F11` または `Alt`+`Enter` |
| 設定 | `Ctrl`+`,` / `Cmd`+`,` |
| 終了 | `Ctrl`+`W` / `Cmd`+`W` |

`Esc` は設定を閉じ、トリミング選択を取消し、編集を終了し、待機中の移動を取消し、全画面を終了します。詳しいキー操作は [docs/development.md](docs/development.md#keyboard-map) を参照してください。

## ビルド

Rust 1.95 以降が必要です（Rust 1.99 で検証済み）。Linux、macOS、Windows に対応し、3 プラットフォームで CI が通っています。プラットフォーム別の依存パッケージとビルド手順は [docs/development.md](docs/development.md#platform-prerequisites) にあります。
